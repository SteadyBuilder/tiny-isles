## 🛠 AI-Friendly Architecture & Contribution Guidelines
본 프로젝트는 **AI-Friendly Architecture Contract**를 표준 개발 규격으로 준수합니다.
자세한 아키텍처 원칙, 코드 품질 기준 및 협업 워크플로우는 [PROJECT_RULES.md](./PROJECT_RULES.md)를 참고하세요.
- **모듈화 & SRP**: 파일당 200~300줄 이내 유지, 단일 책임 원칙 준수
- **Data-Driven**: 데이터와 로직의 분리 (하드코딩 금지, JSON/YAML/상수 분리)
- **Contract-First**: 인터페이스 및 입출력 타입 선행 정의
- **Plan First**: 영향 범위 분석 및 설계 승인 후 단계별 구현
