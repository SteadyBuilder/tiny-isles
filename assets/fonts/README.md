# Pixel Fonts Placement Guide

Place your preferred free Korean pixel fonts here (e.g. Galmuri, DungGeunMo):

Recommended:
- **Galmuri (갈무리)**: `Galmuri9.ttf` or `Galmuri11.ttf` (OFL License)
- **DungGeunMo (둥근모꼴)**: `DungGeunMo.ttf`

You can assign the font in Godot 4 under:
`Project Settings > General > GUI > Theme > Custom Font` or apply it directly to Theme / Labels.
